# Vantage — AI Executive Summary Generator

A small automation script that sits alongside the **Vantage** Power BI
dashboard (an AI-Powered Management Decision & Performance Dashboard
built for a fictional mid-sized Indian FMCG company, ABC Consumer
Products Pvt. Ltd.).

## What it does

Power BI answers *what* is happening and *why*, visually, for anyone
willing to open the report and explore it. This script takes that one
step further: it reads the same underlying data, independently
recomputes the dashboard's core H1-vs-H2 profitability bridge, and
asks an AI model to turn those verified numbers into a short,
plain-English executive briefing — something a manager can read in 15
seconds without opening Power BI at all.

**Example output**, generated from the real dataset:

> While Net Sales saw a healthy 4.4% growth from H1 to H2, increasing
> to Rs.14,095,258, our Gross Profit declined from Rs.6,139,095 to
> Rs.6,016,612, indicating significant margin erosion. This
> profitability drop was driven by Rs.725,121 in discounts and
> Rs.513,341 in increased product costs, which largely offset strong
> volume and price gains of Rs.1,317,421. Logistics costs further
> impacted profit by Rs.201,442, with the East region reporting the
> highest at 10.1%. Specifically, the North region recorded the
> highest discounts at 25.3%, and Home Care remains our weakest-margin
> category with a 32.6% margin. We must prioritize targeted strategies
> to mitigate these specific cost pressures and discount levels to
> restore overall profitability.

## Design principle

**The AI never calculates anything.** Every figure in the output is
computed by this script in plain Python first, using the same
arithmetic as the Power BI DAX measures. The model's only role is
turning correct, pre-computed numbers into fluent prose — it cannot
invent or alter a figure, because it's never asked to calculate one.
This keeps the automation trustworthy: the numbers are governed by
code you can read and verify, not generated by the model.

## Setup

```bash
pip install -r requirements.txt
```

Get a free Gemini API key (no billing required) at
[aistudio.google.com](https://aistudio.google.com), then set it as an
environment variable:

```bash
# macOS / Linux
export GEMINI_API_KEY="your-key-here"

# Windows (cmd)
set GEMINI_API_KEY=your-key-here
```

Place your dataset (`ABC_Consumer_Products_Sales_Dataset_FY2025-26.xlsx`,
with a `Transactions` sheet) in the same folder as the script.

## Run

```bash
python generate_executive_summary.py
```

The script will print the exact prompt sent to the model (so the
input is always auditable), then the generated summary, and save the
result to `vantage_executive_summary.txt`.

## Stack

- **pandas** — reads and aggregates the transaction data
- **Google Gemini API** (`gemini-2.5-flash`, free tier) — generates
  the narrative from the pre-computed figures
- Built as the automation companion to a Power BI dashboard with a
  star-schema data model, a reconciling profit-bridge measure set, and
  a native discount-cap What-if simulator
